## Reading the traces

- Iterations 12 and 13 each compare four seeds. The model/result link selects seed 7; sibling `_seed1`, `_seed2` and `_seed3` files hold the other seeds. Iterations 17 and 18 also have four-seed records.
- Iteration 25 is a STOP-weight selection sweep. Its fold histories live under `arm/models/arm25_w*_fold*_history.json`; it is not one new exported policy.
- Iteration 30 evaluates the existing iteration-23 and iteration-27 models on new targets. [The second evaluation](arm/results/arm1k_e77_phys_stopnet_camera_dots.json) accompanies the first linked above.
- Iteration 33 combines the iteration-13 seed-7 driver with the listed arm model and evaluates eight bearings.
- Iterations 34–36 use seed-specific files in the common model directory. For 37–40, `config.json`'s `lineup` identifies which driver and arm variant was used; [scores.json](arm/results/time_cumulative_test/scores.json) holds their results.
- For 41–57, each condition directory contains `models/config.json`, `test/config.json`, `scores.csv` and `analysis.md`. Frozen disturbance evaluations reuse their parent's weights; a new evaluation is not necessarily new training. [Full-episode training](arm/train_full_episode.py), [disturbance queue](arm/run_curriculum_ladder.py), [recovery programme](arm/run_recovery_programme.py) and [condition definitions](arm/curriculum_conditions) define the work behind these evaluations.
- Historical source hashes may differ from the current source. The original runtime snapshots and full training data are not all in Git; consult [archive availability](arm/results/overnight_20261105/README.md) before attempting an exact replay.
